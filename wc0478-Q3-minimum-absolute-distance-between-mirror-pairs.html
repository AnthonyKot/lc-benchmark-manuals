Minimum Absolute Distance Between Mirror Pairs

Problem Statement

You are given an integer array nums. A mirror pair is a pair of indices (i, j) such that 0 <= i < j < nums.length and reverse(nums[i]) == nums[j]. Reversing removes leading zeros, so reverse(120) = 21.

Return the minimum absolute distance abs(i - j) among all mirror pairs. If no mirror pair exists, return -1.

Constraints: 1 <= nums.length <= 100000, 1 <= nums[i] <= 1000000000.

Problem Essence

The left index must appear before the right index. When scanning from left to right at position j, a valid previous index i must satisfy reverse(nums[i]) == nums[j]. Instead of searching all previous values, remember for each possible future value the latest index that would match it.

The key observation is: after seeing nums[i], store index i under key reverse(nums[i]). Later, when the current value is nums[j], look up nums[j] directly.

Worked Example

For nums = [12, 21, 45, 33, 54]:

IndexValueLookupThen StoreBest
012No key 12 yetreverse(12)=21, store 21 -> 0none
121Key 21 gives previous index 0reverse(21)=12, store 12 -> 11 - 0 = 1
245No key 45 yetreverse(45)=54, store 54 -> 21
333No key 33 yetreverse(33)=33, store 33 -> 31
454Key 54 gives previous index 2reverse(54)=45, store 45 -> 4min(1, 2) = 1

The answer is 1.

Other Official Examples

  • nums = [120, 21] returns 1, because reverse(120) = 21.
  • nums = [21, 120] returns -1. Even though reverse(120) = 21, the required order is i < j, and reverse(21) != 120.

Decision Rule / Algorithm

  1. Create a hash map last where last[x] means: the most recent earlier index whose value reverses to x.
  2. Initialize ans to infinity or -1 as a sentinel.
  3. For each index j and value nums[j], first check whether last contains nums[j].
  4. If it does, update ans with j - last[nums[j]]. This distance is positive because the stored index is earlier.
  5. Compute reverse(nums[j]) and set last[reverse(nums[j])] = j.
  6. Return ans, or -1 if no pair was found.

Using the most recent index per key is enough for the minimum distance: for a fixed current j, the closest valid previous index with the same needed key is the largest such index.

Implementation Skeleton

class Solution:
    def minMirrorPairDistance(self, nums: List[int]) -> int:
        def rev(x: int) -> int:
            y = 0
            while x > 0:
                y = y * 10 + x % 10
                x //= 10
            return y

        last = {}
        ans = 10**9

        for j, value in enumerate(nums):
            if value in last:
                ans = min(ans, j - last[value])
                if ans == 1:
                    return 1
            last[rev(value)] = j

        return -1 if ans == 10**9 else ans

Reimplementation Checklist

  • Check for a match before storing the current index. Storing first can illegally pair an element with itself when the value is a palindrome such as 33.
  • Store under reverse(current), not under current, for the standard one-pass method.
  • Overwrite the stored index for a key with the latest index, because latest gives the smallest distance for future matches.
  • Make reverse(120) equal 21, not 021 or 120.
  • Return -1 only if no candidate was ever found.
  • Early return on distance 1 is safe because no smaller positive index distance exists.

Wrong But Tempting

  • Sorting values or indices loses the required original order and distance.
  • Testing reverse(nums[j]) against earlier raw values is possible, but easy to mishandle with trailing zeros. The standard future-key map avoids that trap.
  • Keeping the first index for each key can miss a shorter pair. Example: if key 21 was produced at indices 0 and 5, and current index is 6, index 5 is the best previous match.
  • Comparing strings without normalizing leading zeros can turn 120 and 21 into a false negative.
  • Using nested loops is too slow for 100000 elements.
