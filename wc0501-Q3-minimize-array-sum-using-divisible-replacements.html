Problem Statement

You are given an integer array nums. You may perform the following operation any number of times:

  • Choose indices a and b such that nums[a] % nums[b] == 0.
  • Replace nums[a] with nums[b].

Return the minimum possible sum of the array after any number of operations.

Constraints from the statement: 1 <= nums.length <= 10^5 and 1 <= nums[i] <= 10^5.

Problem Essence

The array values form a divisibility relation. A value x can be reduced to any original array value d that divides x. Chained operations do not create a better non-original value; every replacement value is copied from some existing element. Therefore each element should independently become the smallest distinct value present in nums that divides it.

The target sum is:

sum(min(d for d in distinct(nums) if x % d == 0) for x in nums)

Since every x divides itself and is present, the minimum divisor always exists.

Worked Example

For nums = [4, 2, 8, 3], the distinct present values are {2, 3, 4, 8}.

The final minimum array can be [2, 2, 2, 3], so the answer is 9.

Decision Rule / Algorithm

  1. Find maxVal = max(nums).
  2. Mark which values are present in the input.
  3. Create an array best, where best[x] will store the smallest present divisor of x.
  4. Process present values d in increasing order. For every multiple m of d, set best[m] to d if it is not already set.
  5. Return sum(best[x] for x in nums).

Because divisors are visited from small to large, the first present divisor assigned to a multiple is the optimal replacement for that multiple. This is a sieve over multiples, with time about maxVal * (1/1 + 1/2 + ...) over present values, bounded comfortably for maxVal = 100000.

Implementation Skeleton

class Solution:
    def minArraySum(self, nums: list[int]) -> int:
        max_val = max(nums)
        present = [False] * (max_val + 1)
        for x in nums:
            present[x] = True

        best = [0] * (max_val + 1)
        for d in range(1, max_val + 1):
            if not present[d]:
                continue
            for m in range(d, max_val + 1, d):
                if best[m] == 0:
                    best[m] = d

        return sum(best[x] for x in nums)

Equivalent accepted variants initialize best[x] = x and only update multiples that are present, or count duplicates first and sum count[value] * best[value].

Reimplementation Checklist

  • Use a 64-bit return type for the sum in fixed-width languages: the maximum sum can reach 10^10.
  • Base the sieve size on max(nums) or the constraint bound 100000.
  • Only divisors that appear in the original input are legal replacement values.
  • Include m = d in the multiples loop, so each value can map to itself.
  • Do not require the target multiple to appear when filling best; filling all multiples is simple and accepted.
  • If optimizing with counts, remember duplicates contribute multiple times to the final sum.

Wrong But Tempting

  • Pairwise simulation: repeatedly scanning all pairs is too slow and unnecessary.
  • Sorting and greedily changing adjacent values: divisibility is not an adjacency relation.
  • Using the gcd of the whole array: the replacement value must already exist as an array element.
  • Following only one operation: an element may be reduced through divisibility logic to the smallest present divisor, but computing that directly is simpler than simulating chains.
  • Using 32-bit sum types: 100000 * 100000 overflows signed 32-bit integers.

Failure Patterns From Stats

stats.json records one failed submission status: Time Limit Exceeded. That is consistent with approaches that compare many pairs or simulate operations until no changes remain. The accepted files avoid simulation and compute all best replacements with a divisibility sieve.

  • Likely TLE shape: for every element, scan every other element as a possible replacement, leading toward O(n^2).
  • Robust accepted shape: iterate over values up to max(nums), not over all index pairs.
  • For n = 100000, the distinction is decisive: value-domain sieving is practical; pair-domain search is not.
