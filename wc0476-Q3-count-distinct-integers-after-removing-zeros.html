Problem Statement

You are given a positive integer n. For every integer x from 1 to n, write down the integer obtained by removing every zero from the decimal representation of x. Return the number of distinct integers written down.

Constraint: 1 <= n <= 10^15.

Official hints: build integers at most n using only digits from 1 to 9; count them with math or digit DP.

Problem Essence

The answer is exactly the count of positive integers y <= n whose decimal representation contains no zero digits.

Every written value has no zeros, because zeros were removed. Conversely, every zero-free integer y <= n appears by choosing x = y. Therefore the task is not about simulating all x; it is a digit counting problem over alphabet {1,2,3,4,5,6,7,8,9}.

Worked Example

n = 10

The written values for x = 1..10 are 1,2,3,4,5,6,7,8,9,1. The distinct set is {1,2,3,4,5,6,7,8,9}, so the answer is 9.

By the zero-free counting view: all one-digit zero-free integers are 1..9, and no two-digit zero-free integer is at most 10. Count: 9.

Decision Rule / Algorithm

  1. Let s = str(n) and L = len(s).
  2. Add all zero-free numbers with fewer digits: for each length k = 1..L-1, there are 9^k choices.
  3. Count zero-free numbers with exactly L digits and value at most n by scanning from left to right.
  4. At position i, with current digit d, choose a smaller nonzero digit for this position. There are d - 1 choices if d > 0, and each leaves 9^(L-i-1) suffixes.
  5. If d == 0, stop. A zero-free number cannot keep matching this prefix, and any positive digit here would exceed n.
  6. If the scan reaches the end without a zero, add one for n itself.

Time complexity is O(number of digits), at most 16 iterations for n <= 10^15. Space is O(1) if powers are carried or recomputed, or O(number of digits) if a small powers array is used.

Implementation Skeleton

function countDistinct(n):
    s = decimal string of n
    L = length(s)
    pow9[0] = 1
    for i in 1..L:
        pow9[i] = pow9[i - 1] * 9

    ans = 0
    for len in 1..L - 1:
        ans += pow9[len]

    for i in 0..L - 1:
        d = integer value of s[i]
        if d > 0:
            ans += (d - 1) * pow9[L - i - 1]
        if d == 0:
            return ans

    return ans + 1

Reimplementation Checklist

  • Use a 64-bit integer return type where the language has fixed-width integer types. The result can exceed 32-bit range.
  • Count 9^k, not 10^k, for shorter lengths.
  • When scanning equal length numbers, add (digit - 1) * 9^remaining, because allowed digits smaller than digit are 1..digit-1.
  • Stop immediately when the corresponding digit of n is zero.
  • Add one at the end only if every digit of n is nonzero.
  • Check edge cases: n = 1, n = 9, n = 10, n = 99, n = 100, n = 101, and n = 10^15.

Wrong But Tempting

  • Simulating 1..n: impossible at n = 10^15.
  • Using a set of transformed values: correct for small inputs, but it still requires iterating all numbers.
  • Counting all numbers without considering the upper bound prefix: summing 9^1 + ... + 9^L overcounts when n is not all nines.
  • Forgetting the zero stop: for n = 101, after matching prefix 1, the zero prevents any same-prefix zero-free continuation from staying under n.
  • Adding n itself unconditionally: n only contributes as a zero-free value if it contains no zeros.
