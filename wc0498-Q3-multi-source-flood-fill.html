Multi Source Flood Fill

Problem Statement

You are given an n by m grid and a list of colored source cells. A source entry [r, c, color] means cell (r, c) starts with that positive color, while every other cell starts uncolored as 0.

At each time step, every colored cell simultaneously spreads its color to its uncolored four-neighbors. If several colors reach the same uncolored cell on the same time step, that cell receives the maximum color among those tied arrivals. Continue until every reachable cell is colored; because the grid is connected under four-neighbor movement, all cells become colored.

Constraints: 1 <= n, m <= 100000, 1 <= n * m <= 100000, 1 <= sources.length <= n * m, colors are in [1, 1000000], and source coordinates are distinct.

Problem Essence

This is nearest-source assignment under Manhattan distance. For each cell, find the minimum distance to any source. Among sources that achieve that minimum distance, assign the largest color. A normal multi-source BFS naturally visits cells in nondecreasing distance, so the only extra care is preserving the "maximum color among same-time arrivals" tie rule.

Worked Example

For n = 3, m = 3, sources = [[0,0,1],[2,2,2]]:

  • Distance 0: (0,0) is color 1 and (2,2) is color 2.
  • Distance 1: color 1 reaches (0,1), (1,0); color 2 reaches (1,2), (2,1).
  • Distance 2: cells (0,2), (1,1), and (2,0) are reached by both colors at the same time, so they take color 2.

Final grid: [[1,1,2],[1,2,2],[2,2,2]].

Decision Rule / Algorithm

Use multi-source BFS. Initialize all source cells with distance 0, their given colors, and enqueue them. When processing a cell at distance d, each neighbor can be handled in one of two accepted ways:

  • Distance-grid approach: if the neighbor is unseen, set distance d + 1, copy the current color, and enqueue it. If the neighbor is already marked with distance d + 1, update its color to the maximum of the current stored color and the incoming color.
  • Level-batched approach: process one BFS layer at a time, collect candidate colors for currently uncolored neighbors in a temporary array or map, keep the maximum candidate per neighbor, and only after the whole layer is scanned write those cells into the grid and enqueue them.

Both encode the same simultaneous-spread rule. The distance-grid version is shorter; the level-batched version makes simultaneity explicit.

Implementation Skeleton

def colorGrid(n, m, sources):
    grid = [[0] * m for _ in range(n)]
    dist = [[-1] * m for _ in range(n)]
    q = deque()

    for r, c, color in sources:
        grid[r][c] = color
        dist[r][c] = 0
        q.append((r, c))

    while q:
        r, c = q.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if outside_grid(nr, nc):
                continue
            if dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                grid[nr][nc] = grid[r][c]
                q.append((nr, nc))
            elif dist[nr][nc] == dist[r][c] + 1:
                grid[nr][nc] = max(grid[nr][nc], grid[r][c])

    return grid

Reimplementation Checklist

  • Allocate an n x m result grid and either a distance grid or per-layer temporary candidate storage.
  • Enqueue every source before BFS starts; do not run separate BFS from each source.
  • Use four directions only: up, down, left, right.
  • Apply the maximum-color tie rule only for arrivals at the same distance/time step.
  • Never let a later, farther wave overwrite a cell that was colored at a smaller distance.
  • Use an index-based queue or deque; repeated front removal from a dynamic array can become too slow.
  • Return the final grid, not the distance grid.

Wrong But Tempting

  • Sequential flood fill per source: this ignores simultaneous arrival and can let source order decide results.
  • Always overwrite with a larger color: a larger color arriving later must not replace a closer smaller color.
  • Only update uncolored cells in a simple queue without same-level tie handling: this can lock in the first color seen for a tie cell.
  • Sorting sources by color: color matters only after minimum distance is tied.
  • DFS recursion: it does not process by time step and may overflow on grids up to 100000 cells.
