Problem Statement

You are given an undirected tree with n nodes numbered from 0 to n - 1, represented by edges. You are also given good, where good[i] == 1 means node i is good and good[i] == 0 means it is bad.

The score of a subgraph is the number of good nodes minus the number of bad nodes in that subgraph. For every node i, return the maximum score among all connected subgraphs that contain i.

Constraints: 2 <= n <= 100000, edges.length == n - 1, good.length == n, every good[i] is either 0 or 1, and edges forms a valid tree.

Problem Essence

Give each node a weight: +1 for good and -1 for bad. A connected subgraph containing a node can be seen as that node plus zero or more adjacent connected branches. A branch should be included exactly when its best contribution is positive; a non-positive branch can only keep the score the same or reduce it.

The key is to compute this "best positive contribution" from every direction of every edge. A normal tree DP gives child-to-parent contributions. A reroot pass supplies the parent-to-child contribution.

Worked Example

Input: n = 5, edges = [[1,0],[1,2],[1,3],[3,4]], good = [0,1,0,1,1].

Weights are [-1,+1,-1,+1,+1]. Root the tree at node 1 for intuition:

  • Leaf 0 contributes -1, so node 1 ignores it unless the answer is specifically for node 0 and connectivity forces node 0 itself.
  • Leaf 2 contributes -1, also ignored by node 1.
  • Node 4 contributes +1 to node 3, so node 3 has contribution +1 + +1 = 2.
  • Node 1 can take node 3's branch, giving +1 + 2 = 3.

For node 0, the connected subgraph must include 0, but can also include the best parent-side branch through 1, 3, and 4: score -1 + 1 + 1 + 1 = 2. Final output: [2,3,2,3,3].

Decision Rule / Algorithm

  1. Convert good[i] into w[i], where good is +1 and bad is -1.
  2. Build an adjacency list for the tree.
  3. Root the tree at any node, usually 0. Record parent and traversal order.
  4. Postorder DP: down[u] = w[u] + sum(max(0, down[v])) over children v. This is the best score of a connected subgraph inside u's rooted subtree that must contain u.
  5. Reroot/preorder DP. For a child v of u, the best contribution from the rest of the tree is outside = ans[u] - max(0, down[v]). Then ans[v] = down[v] + max(0, outside).
  6. Return ans.
The rule max(0, contribution) is the whole optimization. Because the subgraph must stay connected, each included neighbor side is an entire connected branch through that neighbor. Negative branches are never useful.

Implementation Skeleton

function maxSubgraphScore(n, edges, good):
    w = [1 if good[i] == 1 else -1 for i in 0..n-1]
    adj = build adjacency list

    parent = array filled with -2
    order = iterative DFS/BFS order from root 0
    parent[0] = -1

    down = array length n
    for u in reversed(order):
        total = w[u]
        for v in adj[u]:
            if parent[v] == u:
                total += max(0, down[v])
        down[u] = total

    ans = array length n
    ans[0] = down[0]
    for u in order:
        for v in adj[u]:
            if parent[v] == u:
                outside = ans[u] - max(0, down[v])
                ans[v] = down[v] + max(0, outside)

    return ans

Reimplementation Checklist

  • Use +1/-1 weights, not counts of good and bad separately unless the final arithmetic is equivalent.
  • Build an undirected adjacency list with both directions of every edge.
  • Guarantee parent-before-child order for rerooting and child-before-parent order for down.
  • Use iterative traversal in languages where recursion depth is risky for n = 100000.
  • When moving from parent u to child v, subtract only max(0, down[v]), not raw down[v].
  • Allow answers to be negative. A bad isolated node has score -1, not 0.

Wrong But Tempting

  • Returning the global maximum for every node. Each answer must contain that specific node, so a far-away positive component is unusable unless connected through selected nodes.
  • Clamping the whole answer at zero. The connected subgraph must contain the target node, so the minimum possible answer is often -1.
  • Using only subtree DP. Nodes may benefit from branches outside their rooted subtree, so a reroot pass is required.
  • Adding all child scores. Negative child branches should be dropped.
  • Subtracting down[child] instead of max(0, down[child]). If the child branch was not included in the parent answer, subtracting a negative value creates an artificial gain.

Accepted Algorithm Families

All accepted local submissions use linear-time tree rerooting DP. They differ mainly in how the second pass is expressed:

  • Single-answer reroot formula: compute down, set ans[0] = down[0], then use ans[child] = down[child] + max(0, ans[parent] - max(0, down[child])). This appears in the fastest Java and the JavaScript accepted solution.
  • Separate up contribution: compute up[child] as the parent's weight plus positive parent-side and sibling contributions, then answer with down[u] + max(0, up[u]). This appears in the Go and Python accepted solutions.
  • Recursive versus iterative traversal: Python uses recursion with an increased recursion limit; Java, Go, and JavaScript accepted versions use explicit order/stack variants or compact adjacency structures.
