Problem Statement

You are given a rooted tree with nodes 0..n-1, rooted at node 0. Each node i has a positive integer value nums[i]. For every non-root node i, count how many ancestors a on the path from i to root, excluding i, satisfy that nums[i] * nums[a] is a perfect square. Return the sum of these counts for all nodes 1..n-1.

  • 1 <= n <= 100000
  • edges.length == n - 1, and the edges form a valid tree
  • 1 <= nums[i] <= 100000

Problem Essence

The key observation is that two positive integers multiply to a perfect square exactly when their square-free kernels are identical. A square-free kernel is the product of the prime factors whose exponents are odd after factorization.

Examples: 8 = 2^3 has kernel 2; 2 has kernel 2; their product 16 is a square. 12 = 2^2 * 3 has kernel 3.

So the tree problem becomes: for every node, count ancestors with the same kernel as this node.

Worked Example

Input: n = 3, edges = [[0,1],[1,2]], nums = [2,8,2]. Output: 3.

NodeAncestorsChecksCount
1[0]8 * 2 = 16, a perfect square1
2[1, 0]2 * 8 = 16 and 2 * 2 = 4, both perfect squares2

Total: 1 + 2 = 3. In kernel terms, all three values have kernel 2, so each node sees every ancestor on its root path as valid.

Other Official Examples

Decision Rule / Algorithm

  1. Compute max(nums).
  2. Build a smallest-prime-factor table up to that maximum.
  3. Convert each nums[i] into its square-free kernel.
  4. Build an adjacency list for the undirected tree.
  5. DFS from root 0. Maintain freq[k], the number of ancestors currently on the path whose kernel is k.
  6. On entering node u, add freq[kernel[u]] to the answer, then increment it.
  7. After processing children, decrement freq[kernel[u]] to backtrack.

Time complexity is O(max(nums) log log max(nums) + n + total factorization work), practically linear for the given 100000 value bound. Space complexity is O(n + max(nums)).

Implementation Skeleton

function sumOfAncestors(n, edges, nums):
    maxVal = max(nums)
    spf = smallestPrimeFactors(maxVal)

    kernel = array length n
    for i in 0..n-1:
        kernel[i] = squareFreeKernel(nums[i], spf)

    graph = adjacency list from edges
    freq = zero array or map keyed by kernel
    ans = 0

    dfs(root=0, parent=-1):
        k = kernel[root]
        ans += freq[k]
        freq[k] += 1
        for child in graph[root]:
            if child != parent:
                dfs(child, root)
        freq[k] -= 1

    return ans

For languages with shallow recursion limits or uncertain stack size, use an explicit stack with enter and exit states, as the JavaScript, Java, and Python accepted implementations do.

Reimplementation Checklist

  • Use long, long long, int64, or a language integer that can hold up to n * (n - 1) / 2.
  • Do not multiply node values to test for perfect squares; compare square-free kernels instead.
  • Include the root in the path frequency only after counting the root itself, so the root does not count as its own ancestor.
  • Always decrement the current node kernel when leaving a subtree.
  • Handle nums[i] == 1 with kernel 1.
  • Use an iterative DFS if recursion depth can reach 100000.

Wrong But Tempting

  • Checking every ancestor pair directly. This degenerates to O(n^2) on a chain.
  • Testing nums[i] * nums[a] with floating-point square roots. It is slower, unnecessary, and can invite precision mistakes in other bounds.
  • Keeping one global frequency table without DFS backtracking. That counts nodes outside the current ancestor path.
  • Counting descendants or siblings with the same kernel. Only ancestors on the root path count.
  • Using an int result in languages where the worst-case answer can exceed 32-bit range.

Accepted Algorithm Families

All seven accepted files implement the same core family: square-free kernel preprocessing plus DFS path-frequency counting. Differences are mainly engineering choices:

Iterative DFS

JavaScript, Python, and several Java submissions use stack entries like (node, parent, state), where state distinguishes enter from exit. This avoids deep recursion failures on chain-shaped trees.

Recursive DFS

The Go implementation uses recursive DFS with a path frequency array and backtracking. The logic is compact but depends on the runtime stack being adequate.

Kernel Storage

Some submissions precompute kernels for every node only. The JavaScript solution precomputes square-free values for all values up to 100000.
